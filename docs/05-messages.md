### 1. `{Greeting}`
```
Привет! Я бот логист.
Помогаю автоматизировать работу.

Выберите раздел ниже, чтобы начать 👇
```

---

### 2. `{On}`
```
✅ Запущено

Бот начал работу и будет присылать уведомления
согласно вашим настройкам.
```

---

### 3. `{Off}`
```
⏹ Остановлено

Бот приостановлен. Уведомления приходить не будут,
пока вы не включите его снова.
```

---

### 4. `{Config}`
```
⚙️ Настройки

Здесь можно изменить параметры работы бота:
- 💰 Цена за км — влияет на расчёт стоимости поездки/заказа

Выберите пункт, который хотите изменить 👇
```

---

### 5. `{PricePerKM}`
```
💰 Укажите цену за 1 км

Отправьте число (например: 25 или 25.5).

Текущее значение: {current_price} ₴\км
```

---

### 6. `{PriceUpdated}`
```
✅ Цена обновлена: {new_price} ₴/км

Изменения вступили в силу и будут применяться
ко всем новым расчётам.
```

---

### 7. `{PriceInvalid}`
```
⚠️ Не удалось распознать число.

Пожалуйста, отправьте цену цифрами, например: 30
```

---

### 8. `{Source}`
```
📡 Источники данных

Выберите, какие источники использовать.
✅ — включён, ❌ — выключен.

Нажмите на источник, чтобы переключить его состояние 👇
```

---

### 9. `{SourceOn}`
```
✅ Источник «{name}» включён

Теперь данные из этого источника будут учитываться
в работе бота.
```

---

### 10. `{SourceOff}`
```
❌ Источник «{name}» выключен

Данные из этого источника больше не используются.
```

---

### 11. `{Payment}`
```
💳 Оплата

Доступные варианты оплаты:
- Банковская карта (Visa/Mastercard)

Стоимость подписки: {price} ₴/{period}
```

---

### 12. `{Card}`
```
💳 Оплата картой

Перейдите по ссылке ниже, чтобы завершить оплату:
👉 {payment_link}

Ссылка активна в течение 15 минут.
После оплаты доступ обновится автоматически.
```

---

### 13. `{PaymentSuccess}`
```
🎉 Оплата прошла успешно!

Спасибо! Доступ активирован до {expiration_date}.
```
