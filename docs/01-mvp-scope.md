# Telegram bot
A Telegram bot that aggregates freight/logistics posts from external sources (e.g. Telegram channels), parses routes and prices, and delivers matching listings to subscribed users.

# Features
- Notification for new orders with price/km higer then {price_per_km}:
    - Parser (MTProto)
    - Normalizer + Matcher
    - Bot
    - Cron
    - Cross-source deduplication

# Sources
- Type: Telegram; Source: Telegram channels/chats

# Payment methods
- Monobank Acquiring

# Currencies
- UAH

# Subscription
   - Paid access via recurring subscription
   - Auto-renewal on repeat payment, expiry reminders, access revoked on expiry
